AST Codebase Scanning

Combines Tree-sitter AST syntax parsing with Radon (complexity), Vulture (dead functions/variables), and Bandit (security vulnerabilities).

Dependency Graph Intelligence

Maps module imports and caller hierarchies with NetworkX. Computes blast radius before modifications so no downstream callers break.

core/graph.py

Interactive Fix Review Studio

Presents candidate fixes in unified side-by-side diff viewers with test feedback and explicit developer Approve and Reject actions.

Semantic Vector Search

Embeds codebase functions into ChromaDB vector store. Search natural language concepts (e.g. "find database rollback handlers").

memory/chroma.py

Developer Decision Memory

Stores approvals and rejections in SQLite. The prompt synthesizers query past rejections to avoid repeating unwanted patch patterns.

memory/sqlite.py

Isolated Branch Sandbox

Never mutates your primary branch directly. Generates changes on isolated agent-fix-* branches with automatic force-rollback on test failure.

main.py

Developer Onboarding

Get started in five minutes.

Run the entire system locally with Python 3.11 or 3.12.

Environment:
01 · CLONE REPOSITORY

Clone the project repository to your development machine.

git clone https://github.com/jayeshtak/Codebase-Self-Evolving-Agent.git cd Codebase-Self-Evolving-Agent
02 · VIRTUAL ENVIRONMENT

Initialize an isolated Python 3.12 virtual environment.

python -m venv venv .\venv\Scripts\Activate.ps1 python3 -m venv venv source venv/bin/activate
03 · INSTALL DEPENDENCIES

Install all analysis engines and API server dependencies.

pip install -r requirements.txt
04 · LAUNCH SERVER

Start the FastAPI server on port 8000.

python -m uvicorn ui.server:app --host 127.0.0.1 --port 8000
Then navigate to: http://127.0.0.1:8000/app

Questions & Clarifications

Frequently asked.

Clear, honest answers about safety boundaries and operational constraints.

How does the agent avoid breaking working code? +

Fixes are never committed to your active branch. The system creates isolated agent-fix-* branches, runs your test suites (pytest), critiques the diff through a second independent model (Groq Llama 3.3 70B), and forces an immediate rollback to clean HEAD if tests fail.

Do I need to pay for API keys to run the agent? +

No. The core AST static analysis, Radon complexity scoring, Vulture dead-code discovery, Bandit security audit, and NetworkX dependency graph run 100% offline with zero API keys. API keys (Gemini or Groq) are only optional when activating the generative patch synthesis loop.

Can it run against remote repositories? +

Yes. You can paste any public Git URL into the Workspace Input. The application clones the repository into an isolated sandbox in /tmp, establishes branch references, and indexes ASTs without polluting your local working directory.

How does the decision memory prevent repeated bad suggestions? +

When you reject a proposed change, the rejection rationale and code slice are stored in SQLite memory.db. When synthesizing future patches for related files, the Coder agent queries past rejections and explicitly suppresses unwanted patterns.

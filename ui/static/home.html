Your Codebase.
Understood. Improved. Evolving.

What is this? An open-source tool that scans your codebase for technical debt and security oversights, maps dependency impact, generates verified fixes on isolated Git branches, and asks for your review before anything merges.

Open Developer Console Scroll Stacking Guide
Local & Offline

Tree-sitter AST, Radon, and Bandit scans run locally without sending source code externally.

Isolated Branches

Fixes run on temporary agent-fix-* branches with automatic test rollback.

You're in Control

Zero silent merges. You inspect before-and-after diffs and click approve before anything applies.

01 · REPOSITORY core/git_manager.py

Point to Your Codebase

Enter your local folder path or any public GitHub URL into the console. The agent indexes your project files without touching existing branches.

Safety Guarantee

Repository is opened in read-only sandbox mode. No accidental file modifications occur during initialization.

02 · SCANNER agents/scanner.py

Scan with Multi-Engine AST Tools

The agent parses code using Tree-sitter for syntax analysis, Radon for cyclomatic complexity, Vulture for dead code, and Bandit for Python security vulnerabilities.

Safety Guarantee

Runs 100% locally on your machine. Zero code or tokens are ever sent to any cloud server.

03 · PLANNER core/graph.py + NetworkX

Map Call Graphs & Blast Radius

Before proposing a change, the agent builds an import and caller graph with NetworkX. It calculates the blast radius of any modification so downstream functions never break.

Safety Guarantee

High-risk changes with multiple callers are automatically flagged with warning scores and isolated.

04 · CODER core/patcher.py (LibCST)

Generate Precise AST Patches

The Coder agent generates targeted fixes. Instead of guessing text replacements, it uses LibCST to replace specific AST syntax nodes on an isolated agent-fix-* candidate branch.

Safety Guarantee

Modifications happen on temporary candidate branches. Your primary branch is completely untouched.

04_ast_patch.diff
CANDIDATE_READY 
--- a/auth/hasher.py
+++ b/auth/hasher.py
@@ -12,4 +12,4 @@
 def hash_user_token(raw_token: str) -> str:
-    # Insecure MD5 hash
-    return hashlib.md5(raw_token.encode()).hexdigest()
+    # Upgraded to SHA-256 with UTF-8 byte encoding
+    return hashlib.sha256(raw_token.encode('utf-8')).hexdigest()
05 · REVIEWER agents/reviewer.py + Pytest

Automated Review & Test Verification

The agent executes your test suite with pytest on the candidate branch. A secondary reviewer model verifies the diff to ensure original caller signatures and types are preserved.

Safety Guarantee

If any tests fail or syntax errors are detected, the candidate branch is automatically rolled back.

06 · APPROVAL ui/static/index.html + memory/sqlite.py

You Inspect and Decide

The candidate fix is presented in your browser console. You inspect the before-and-after diff and click Approve or Reject. Your decision is recorded in SQLite memory to guide future runs.

Safety Guarantee

Zero silent merges. Nothing is merged into your project without your direct approval click.

Your Codebase.
Understood. Improved. Evolving.

What is this project? It is an open-source development agent that inspects your software codebase, discovers bugs, dead code, and security vulnerabilities with local AST tools, proposes targeted fixes on isolated Git branches, and asks for your review before anything touches your code.

Open Developer Console See How It Works
100% Offline Core
AST parsing, Radon complexity, and Bandit SAST run locally with zero API keys required.
Isolated Git Branches
Fixes run on temporary agent-fix-* branches with automatic rollback on test failures.
Human-Governed
Zero silent merges. You review before-and-after diffs and click approve before anything is applied.
